# Quant Learning Repository

A curated collection of resources, notes, and roadmaps for becoming a good quantitative researcher/trader/developer.

## What This Is

This repo is a **learning hub**, not a code library. It collects the best books, papers, courses, and practical exercises for building quant skills math, statistics, programming, market microstructure, and strategy research. Contributions are welcome from anyone who has found something genuinely useful.

## Who This Is For

- Aspiring quants with a math/CS/physics background
- Developers moving into quant finance
- Students preparing for quant internships/interviews
- Anyone who wants a structured path

## How the Repo Is Organized

```
/interviews       # quant interview prep and brainteasers
/markets          # microstructure, asset classes, market conventions
/math             # probability, statistics, linear algebra, stochastic calculus
/papers           # annotated reading lists of key papers
/programming      # Python, C++, data tooling, backtesting frameworks
/projects         # hands-on exercises and mini-projects
/roadmap          # suggested learning paths (beginner → advanced)
/strategies       # classic strategies and the theory behind them
/resources.md     # master list of books, courses, blogs, podcasts
```

## Where to Start

1. Read [`roadmap/README.md`](roadmap/README.md) — pick a track based on your background.
2. Skim [`resources.md`](resources.md) — the master index of everything here.
3. Try one project from [`projects/`](projects/) to test what you've learned.

Suggested beginner path: **probability → Python → basic backtesting → market microstructure → first strategy project**.

Please read [`CONTRIBUTING.md`](CONTRIBUTING.md) before your first PR.
