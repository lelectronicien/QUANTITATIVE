# Quant Learning Repository

A curated learning hub for quantitative research, trading, and development.

## Purpose

This repository collects annotated resources, notes, and exercises covering mathematics, statistics, programming, markets, and quantitative research. It is an educational resource, not a production trading library.

## Structure

- [Roadmap](roadmap/README.md) — learning path (currently being developed).
- [Mathematics](math/) — probability and statistics notes (in progress).
- [Programming](programming/) — Python, Git, and Bash tutorials.
- [Markets](markets/) — market structure notes (in progress).
- [Papers](papers/) — reading list (in progress).
- [Interviews](interviews/) — preparation notes (in progress).
- [Projects](projects/) — hands-on projects (in progress).
- [Resources](resources.md) — resource index (in progress).

## Getting started

1. Start with [the Python study plan](programming/python/00_plan_of_study.md).
2. Read [basic functions](programming/python/01_basis_function.md), [data types](programming/python/02_variable_and_data_type.md), and [operators](programming/python/03_operators.md).
3. Continue with [conditions, functions, and advanced Python](programming/python/command.md).
4. Explore the other sections as content becomes available.

## Contributing

Contributions are welcome. Open an issue describing the proposed addition or correction, then submit a focused pull request. Explain why each new resource is useful, its difficulty level, and whether access is free or paid. Avoid promotional content, unlicensed copies of copyrighted works, and unsupported performance claims.

## Quality standards

Resources should be relevant, accurate, annotated, and accessible. Code examples should be runnable or explicitly marked as illustrative. Quantitative results should state assumptions, costs, sample sizes, and limitations.
